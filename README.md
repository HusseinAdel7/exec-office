# مكتب المدير

نظام لإدارة أعمال المدير والشركات التابعة له: المواعيد والاجتماعات، القضايا والجلسات، الرحلات، العقود، الموافقات، المهام، المكالمات والزوار، جهات الاتصال، وأرشيف المرفقات مع بحث داخل محتوى الملفات.

## التشغيل

افتح رابط GitHub Pages الخاص بالمستودع، أو افتح ملف `index.html` مباشرة في المتصفح.

## أين تُحفظ البيانات؟

- البيانات والمرفقات تُحفظ **داخل المتصفح على الجهاز نفسه** (localStorage و IndexedDB)، ولا تُرفع إلى GitHub إطلاقاً.
- كل جهاز له بياناته الخاصة. لنقل البيانات بين الأجهزة: **الإعدادات ← تنزيل نسخة احتياطية**، ثم **استعادة من نسخة احتياطية** على الجهاز الآخر.
- النسخة الاحتياطية تحفظ بيانات المرفقات ونصوصها المستخرجة، أما الملفات نفسها فتبقى على الجهاز الذي رُفعت منه.

## الملفات

- `index.html` — الصفحة
- `styles.css` — التصميم
- `app.js` — منطق النظام
- `build.js` — يجمع الملفات في صفحة واحدة (للنسخة المنشورة على Claude)

## التشغيل مع قاعدة بيانات SQL Server (شبكة المكتب)

مجلد `server` فيه API بـ ASP.NET Core بيربط الموقع بقاعدة SQL Server، مع تسجيل دخول ومزامنة بين الأجهزة.

1. لازم يكون متسطب على الجهاز: SQL Server (أو Express) و .NET SDK.
2. اضبط سطر الاتصال في `server/appsettings.json` لو اسم السيرفر مختلف عن `.\SQLEXPRESS`.
3. شغّل `server/start-server.bat` — السيرفر بينشئ قاعدة `ExecOffice` والجداول لوحده.
4. افتح `http://localhost:5080` وأنشئ حساب مدير النظام، وبعدين ضيف باقي المستخدمين من الإعدادات.
5. من أجهزة المكتب: `http://IP-جهاز-السيرفر:5080` (لازم تفتح البورت 5080 في Windows Firewall).

ملف `server/schema.sql` فيه شكل الجداول للمرجعية.
